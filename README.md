# AI/ML Based DC Bus Voltage Regulation (Replacing Classical PI Controller)

## 1. Problem Overview & What the Assignment is Asking For

This project addresses the design of an **Intelligent Closed-Loop Voltage Controller** for a DC Bus (e.g. in DC Microgrids, Solar PV / Battery Converters, or EV Fast Chargers).

### Objective:
Replace the conventional **Proportional-Integral (PI) Controller** with an **AI/ML Control Technique** to minimize the voltage error:
$$V_{err}(t) = V^*(t) - V_{dc}(t)$$
under steady-state and severe load disturbance conditions.

```
       Reference V* (300V)
              │
              ▼   +
          ┌───────┐      Verr       ┌────────────────────────┐   Control u(t)   ┌────────────────┐   Sensed V
          │   Σ   │ ──────────────> │   AI / ML Controller   │ ───────────────> │  DC Bus Plant  │ ─────────┐
          └───────┘  -              │ (Fuzzy Logic / Neural) │                  │  (C * dV/dt)   │          │
              ▲                     └────────────────────────┘                  └────────────────┘          │
              │                                                                                             │
              └─────────────────────────────────────────────────────────────────────────────────────────────┘
```

### Critical Requirement:
> **"It is not a prediction problem, Do not run prediction model with Data, Aim of project is to reduce (Verr) PI input as much as possible."**
> 
> *Explanation*: You are **not** forecasting future voltage values via time-series regression. Instead, you are designing a **feedback controller** using AI/ML techniques (Fuzzy Logic, Neural Networks, Neuro-Fuzzy ANFIS) that responds dynamically in closed loop to eliminate deviations and minimize $V_{err}$.

## 2. Dataset Breakdown (`Case Study DCbusData.csv.xlsx`)

The dataset provides 120,001 data points recorded from the baseline PI controller operation:
1. **`Vdc reference`**: Constant 300.0 V setpoint.
2. **`Vdc Sensed`**: Measured DC bus voltage (ranges between 256 V and 322 V due to disturbances).
3. **`PI Input` ($V_{err}$)**: Tracking error ($V^* - V_{dc}$), with peaks up to **+43.6 V / -21.6 V** and baseline **RMSE = 3.49 V**.
4. **`PI Output` ($u(t)$)**: Control command generated by the baseline PI controller.

---

## 3. Implemented AI/ML Control Techniques

### Technique 1: Fuzzy Logic Controller (FLC / ANFIS)
- **Inputs**: 
  1. Error $e(t) = V^* - V_{dc}$
  2. Rate of Change of Error $\Delta e(t) = \frac{de}{dt}$
- **Rule Base**: 25 Mamdani/Sugeno linguistic rules spanning `{NB, NS, ZE, PS, PB}`.
- **Advantage**: Instantaneous nonlinear damping during sudden load steps without integral windup.

### Technique 2: Adaptive Neural Network Controller (ANN / Neuro-PI)
- **Architecture**: Multi-layer perceptron with non-linear hyperbolic tangent hidden neurons.
- **Adaptive Gain Scheduling**: Dynamically computes optimal instantaneous control actions $u(t)$ and gains $[K_p(t), K_i(t)]$ to minimize the tracking loss $J = \int (V^* - V_{dc})^2 dt$.
- **Advantage**: Superior adaptive learning, clamping peak disturbance dips/swells by over 70–80%.
